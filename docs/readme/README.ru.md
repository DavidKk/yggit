## Почему Yggit?

Современная разработка всё чаще включает несколько репозиториев, параллельные ветки, изолированные worktree и одновременную работу нескольких AI-агентов. Обычные Git-клиенты часто ограничиваются жёсткими сетками коммитов или базовым просмотром diff.

Yggit объединяет **органический граф коммитов Древо Мира**, **проактивную диагностику репозиториев** и **открытого local-first AI-ассистента** в одном пространстве — прямо в браузере, как локальный сервер или как автономное десктопное приложение.

## Основные возможности

### Git, brought to life — Визуализация Древо Мира

Замените жёсткие схемы метро на **органический DAG Древо Мира**: плавные кубические кривые Безье, визуальная иерархия основного ствола и боковых веток, бесшовные разделители по датам и семантические узлы (капсулы Stash, пульсирующее кольцо HEAD, узлы слияния).

### Meet Yggi — Встроенный AI-ассистент репозитория

Доступен в виде перетаскиваемой плавающей пилюли, карточки быстрого ответа или боковой панели. Задавайте вопросы о ветках, diff и слияниях, генерируйте сообщения коммитов, цитируйте ответы и используйте **Agent Spotlight** с уровнями достоверности Fact / Derived / Hypothesis.

### Stay ahead of Git problems — Диагностика Workdesk

**Workdesk** непрерывно сканирует активные репозитории, выявляя рассинхронизацию веток, неотправленные коммиты на ревью, расхождения веток, лишние worktree и нарушения именования до возникновения конфликтов.

### One workspace, many repositories — Мультирепозиторий и Worktree

Легко переключайтесь между локальными и удалёнными репозиториями и настраивайте контекстное меню веток: закреплённые быстрые действия, каскадные подменю, двухэтапное подтверждение опасных операций и адаптивная фильтрация.

### Your code stays yours — Local-first и приватность

**Local-first по умолчанию**: индексы, кэши и зашифрованные учётные данные хранятся на вашем устройстве, а встроенное обратимое маскирование на клиенте скрывает токены, email и секреты перед отправкой во внешние модели.

### Bring your own AI — Открытая экосистема AI и MCP

Подключайте любые удобные модели без привязки к поставщику:

- **Browser AI** — встроенный в Chrome Gemini Nano.
- **Browser Local AI** — офлайн-модели прямо в браузере через WebGPU / WASM.
- **Локальные CLI-агенты** — адаптеры для Claude, Codex, Gemini, Cursor и Antigravity CLI.
- **OpenAI-совместимые и облачные API** — DeepSeek, OpenAI, Claude, Ollama и собственные шлюзы с wildcard-фильтрами.
- **Skills и HTTP MCP** — импорт `SKILL.md` (локально или с GitHub) и подключение Streamable HTTP MCP-серверов с кастомными заголовками или MCP OAuth 2.0 (PKCE).

## Создано для AI Coding

Когда несколько AI-агентов одновременно меняют разные ветки и worktree, состояние Git быстро усложняется. Yggit помогает удерживать порядок:

- **Единый обзор Worktree и агентов** — отслеживайте активные worktree, неслитые коммиты и расхождения веток.
- **Ранняя проверка синхронизации и конфликтов** — заранее выявляйте отставание от remote и риски 3-way конфликтов.
- **Понимание Diff и истории с AI** — Yggi помогает суммировать изменения и отслеживать историю слияний на графе.
- **Поддержка 10 языков** — английский, китайский (упрощённый и традиционный), японский, корейский, французский, немецкий, испанский, бразильский португальский и русский.

## Режимы работы

Yggit работает в трёх режимах (`YGGIT_SERVICE`) с единым интерфейсом:

| Режим              | Как работает                                            | Доступ к диску и Git                                                                                        |
| ------------------ | ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Local**          | Node.js-сервер рядом с вашими репозиториями             | Полный нативный Git CLI, локальные файлы, шифрованное хранилище и локальные CLI-агенты                      |
| **Desktop App**    | Автономное Electron-приложение (`YGGIT_SERVICE=app`)    | Полный нативный Git CLI, локальные файлы и интеграция с ОС                                                  |
| **Edge / Browser** | Браузерный режим без установки (`YGGIT_SERVICE=remote`) | Без серверного диска — открывает локальные папки в Chromium через File System Access API (`isomorphic-git`) |

## Приватность по дизайну

- **Без аккаунта**: начинайте работу сразу, без регистрации и телеметрии.
- **Локальное хранение**: индексы, кэши и зашифрованные токены остаются на вашем устройстве.
- **Прозрачные внешние границы**: запросы отправляются только на настроенные вами LLM/MCP-эндпоинты с опциональным клиентским маскированием. Подробнее в `/settings/privacy`.

## Быстрый старт

Требуются **Node.js ≥ 22.19.0** и **pnpm**.

```bash
git clone https://github.com/DavidKk/yggit.git
cd yggit
pnpm install
pnpm dev
```

Откройте [http://localhost:3000](http://localhost:3000) (или LAN-адрес из логов запуска).

<details>
<summary>Команды разработки, тестирования и сборки Desktop App</summary>

| Команда             | Назначение                                                                            |
| ------------------- | ------------------------------------------------------------------------------------- |
| `pnpm dev`          | Запуск dev-сервера (по умолчанию слушает LAN)                                         |
| `pnpm dev:lan`      | Явный LAN dev-сервер                                                                  |
| `pnpm dev:loopback` | Только loopback (`127.0.0.1`)                                                         |
| `pnpm build`        | Сборка production-бандла Next.js                                                      |
| `pnpm build:app`    | Сборка standalone App и подготовка `.electron-builder/app-root`                       |
| `pnpm dist:mac`     | Сборка `.app` и `.zip` для macOS (`x64` + `arm64`)                                    |
| `pnpm dist:win`     | Сборка NSIS-установщика Windows (`.exe`)                                              |
| `pnpm dist:dir`     | Сборка распакованного каталога для локальной проверки                                 |
| `pnpm electron`     | Запуск Electron с Next dev-сервером                                                   |
| `pnpm start`        | Запуск production-сервера                                                             |
| `pnpm ok`           | Запуск `fix:imports`, Prettier, ESLint (`--max-warnings=0`), typecheck, Jest и сборки |
| `pnpm ok:ci`        | Полная CI-проверка                                                                    |

</details>
