## 1. 交互与设计哲学

Yggit Workdesk 是**以 Git 为中心、以任务为载体**的虚拟研发同事。其核心交互遵循以下五大原则：

1. **克制沉静，拒绝仪表盘化**：
   不引入喧宾夺主的大屏统计图表、进度圆环或复杂看板标签。采用 Yggit 原生低饱和灰白背景与标志性的青绿（Teal `#079b85` / `#169b80`）点缀，保持阅读代码时的清爽与专注。
2. **轻量网格，自适应一屏**：
   借鉴看板列的横向分类逻辑，但不抄袭 Trello 的厚重灰底与密集徽章。桌面端采用四列等宽自适应网格，优先一屏呈现全部工作，不以横向滚动为默认布局。
3. **极简下钻，直达证据**：
   去除冗余的中间过渡和复杂工具栏。从卡片点击直达**左清单 / 右详情**视图；详情页内以可导航的 Git 证据（Commit、文件、冲突）为第一公民，点击即刻深入原生工作区。
4. **无感药丸，按需委托**：
   沿用屏幕底部常驻的 Git Agent 药丸与右侧抽屉式聊天侧栏。任务详情页不重复做“交给 Agent”按钮；唤起药丸时自动绑定当前上下文。
5. **规范化图标体系**：
   **严禁在 UI 界面中使用原始 Unicode Emoji**。所有界面图标均严格选用 `react-icons`（如 `react-icons/lu`、`react-icons/io5`）。

## 3. 看板与组件视觉规范

### 3.1 四大工作场景分类定义与 UI 映射

| 分类标识 (`lane`) | 中文名称     | 推荐图标 (`react-icons/lu`) | 语义色彩                  | 典型任务                                   |
| ----------------- | ------------ | --------------------------- | ------------------------- | ------------------------------------------ |
| `branch`          | **分支维护** | `LuGitBranch`               | Teal (`#079b85`)          | 同步默认分支、检查并行开发工作、清理死分支 |
| `merge`           | **合并集成** | `LuGitMerge`                | Blue (`#5878aa`)          | 多分支组合预演、主干合入检测、冲突定位     |
| `standard`        | **研发规范** | `LuFlag`                    | Amber (`#a6751c`)         | 核查测试分支变更、发布路径审查、规则校验   |
| `review`          | **代码审查** | `LuCheckCircle`             | Purple / Teal (`#4a8e7e`) | 审查冲突解决结果、变更影响面核对           |

分类头部包含：左侧类别图标、分类标题（加粗 12px）、右侧该分类下的未关闭卡片计数徽标（小字 11px 浅灰）。

### 3.2 紧凑工作卡片 (WorkCard)

- **尺寸与间距**：高度自适应（最小约 52–59px），内边距 `9px 10px`，圆角 `8px - 11px`；
- **边框与阴影**：默认 `1px solid var(--line)`（浅灰 `#e7ebed`），无厚重投影；
- **悬停态 (Hover)**：背景微变淡青绿（`#f8fcfa`），边框变为 `#b5ddd4`，微光泽阴影，不产生剧烈位移；
- **内部排布**：
  - 左侧：工作图标胶囊容器（22–27px 宽高，浅灰绿背景 `#eef5f2`）；
  - 中间：工作主标题（12px，粗度 650，单行或两行截断）+ 影响范围（10–11px，浅灰，如 `5 个项目`、`3 个项目 · 4 Worktrees`）；
  - 右侧：进入指示箭头（`LuChevronRight`，浅灰，14px）；
- **行为规范**：整卡可点击，点击后平滑转场进入该任务详情。

## 4. 任务详情页交互规范 (Task Navigation & Evidence)

任务详情页采用**左侧导航清单 + 右侧 Git 证据详情**的固定布局，顶部带简洁的返回面包屑：

```text
← 返回任务卡片    同步默认分支                           Git Workdesk
+-------------------------+----------------------------------------------+
| 任务列表                 | Yggit · master              ● 检查通过        |
|                         | 远程领先，可安全快进                           |
| Yggit                   |                                              |
| [✓] master              | -------------------------------------------- |
|     远程领先，可安全快进  | 相关 Git 内容 (点击直接定位)                   |
|                         | ⑂ Commit a84c2e1 (查看提交及分支关系)       ↗ |
| Ticket Janitor          | ▤ README.md (查看文件内容与 Diff)          ↗ |
| [!] master              |                                              |
|     本地工作区有未提交变更| -------------------------------------------- |
|                         | 需要协助时，使用下方 Git Agent 药丸     ···  |
+-------------------------+----------------------------------------------+
```

### 4.1 顶部通栏导航 (Topline)

- 左侧：返回按钮 `← 返回任务卡片`（`LuArrowLeft`），点击回到看板并恢复先前滚动位置；
- 中间：当前聚合任务大标题（13px，居中加粗）；
- 右侧：模块标识 `Git Workdesk`（10px，弱化浅灰）。

### 4.2 左侧任务导航清单 (Task Navigation)

- **分项目分组**：多仓库任务按仓库名称（Project Alias）划分子分组；分组头以微小浅灰字号呈现；
- **子任务项 (Nav Item)**：
  - 呈现子任务名称（如 `master`、`feature/auth`）与简要状态；
  - 右侧包含轻量状态指示圆点（State Dot）：
    - 绿色（`#28a388`）：检查通过 / 安全可快进；
    - 黄色（`#d8a646`）：需关注 / 存在工作区未提交等注意项；
    - 红色（`#d96c61`）：存在风险 / 冲突 / 分支分叉。
  - **当前选中态**：浅青绿背景（`#e8f3ef`），文字微加粗，与右侧详情保持响应联动；
- **单子任务模式**：若该任务仅包含一个子任务，左侧自动收起为极简的单任务胶囊，不显示多余列表。

### 4.3 右侧证据详情 (Git Evidence Detail)

- **标题与状态**：呈现 `{仓库} · {分支/子任务}` 以及当前项综合状态指示圆点；
- **核心结论**：一句话直击要害（如“远程领先，可安全快进”或“第 2 步在 src/auth.ts 产生冲突”）；
- **可导航 Git 证据项 (Evidence Rows)**：
  - 每行由图标容器（`LuGitCommit`、`LuFileCode`、`LuAlertTriangle` 等）、证据内容（Commit OID、文件路径、步骤说明）以及右上角外链指示（`LuExternalLink`）构成；
  - 悬停时高亮，点击**直接跳转到 Yggit 既有原生工作区**（Commit Graph、File Diff 或 3-Way 冲突视图）；
- **底部辅助区**：
  - 简短提示文案：“需要协助时，使用下方 Git Agent 药丸”；
  - 右下角低频更多操作（`LuMoreHorizontal`）：点击弹出气泡菜单，提供“从工作台移除卡片”（不物理删除底层 Finding，仅标记为工作台归档）。

## 5. Agent 药丸与协同交互

1. **药丸常驻表现**：
   - 固定于屏幕底部正中（`bottom: 19px`），白色圆角胶囊药丸，带青绿色边框与微阴影；
   - 图标使用 `LuSparkles` 或 `LuBot`，文案常驻为 `Git Agent`。
2. **上下文自动注入**：
   - 当在任务页中点击药丸展开右侧侧栏时，Agent 对话初始化提示自动带入：  
     `“我已经收到当前工作上下文：当前子任务：同步默认分支 / Yggit · master。我可以先执行已授权的只读检查、聚合证据、准备方案。”`
3. **分栏协同不遮挡**：
   - 侧栏展开时，主画布容器右边距增加 `370px`，整体优雅压缩，不遮挡左侧清单与右侧证据项。

## 6. Portable Check 导入交互规范

1. **入口与预览**：
   - 用户打开带有 `#data=...` 的分享链接时，展示“导入同事的检查方案”对话卡片；
   - 明确提示：“共享的是仓库标识、分支及检查参数，不包含完整 Git Diff、源码或个人任务数据库。在你确认之前不会自动执行任何检查。”
2. **仓库匹配矩阵 (Repo Matching)**：
   - 逐项列出配方中的仓库；
   - 本地已匹配：展示绿色 `已匹配` 徽标与勾选；
   - 本地缺失：展示 `选择仓库` 按钮，点击唤起项目选择器完成关联；
3. **部分验证操作**：
   - 底部操作栏展示：`已匹配 1/4 · 允许部分验证`；
   - 提供“验证已匹配项目”主按钮，支持跳过缺失项目先行检查已接入项目。

## 7. 动画与可访问性 (a11y)

- **转场过渡**：页面退场与进场动画时长控制在 `180ms - 220ms`，采用轻量 CSS `opacity` 与 `translateY(6px)` 组合；
- **动态效果减弱支持**：当检测到系统开启 `@media (prefers-reduced-motion: reduce)` 时，关闭所有位移动画，直接无延迟切换；
- **无障碍与按键**：所有卡片与证据行均为原生 `<button>` 或带 `role="button"` 的键盘可聚焦元素，支持 Enter / Space 键唤起。
