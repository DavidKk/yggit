# 浏览器本地模型与免费在线 AI 接入 PRD

> 状态：已通过前置可行性验证（2026-11-26）

## 1. 背景与目标

Yggit 定位为 Edge-First（端侧优先）、零存留的 Git 可视化与智能工作台。目前已支持 Chrome 原生 `Browser AI`（Prompt API / Gemini Nano）与自建 OpenAPI 渠道。为了进一步降低使用门槛并满足「完全离线 / 当前域本地缓存」与「免配置免费在线体验」两类需求，本次新增两类接入能力：

1. **Browser Local AI（浏览器下载本地模型）**：与 `Browser AI` 同属「浏览器与本地模型」分组，默认推荐 **Qwen3.5 0.8B (Q4, ~635 MB)**，并可选超轻量 **LFM2.5 350M (Q4, ~283 MB)**。用户点击下载后直接从 Hugging Face Hub 拉取 ONNX 权重并缓存在**当前域（Origin）**浏览器存储中，推理全程在端侧执行，不经过任何官方后端。
2. **Free Online AI（免费在线模型评估与接入）**：基于真实网络与 CORS 实测结论，筛选真正可用的免 Key / 免费在线接入方式，避免引入不可用或高风险断点。

## 3. 核心需求

### 3.1 渠道分组与模型目录

- 在模型配置页渠道下拉框的 **「浏览器与本地模型」** 分组中新增 `Local Model (Browser Download)`：
  - **推荐默认**：`Qwen3.5 0.8B (Q4 · ~635MB)` — 平衡中文/多语言代码理解与体积；
  - **超轻量备选**：`LFM2.5 350M (Q4 · ~283MB)` — 极速下载体验。
- 不自动在后台静默下载数百 MB 模型，必须由用户主动点击下载/启用。

### 3.2 下载进度与右上角全局感知

- 复用已接入的右上角 [DownloadCenter](file:///Users/davidjones/Develop/ops/apps/yggdrasil/components/downloads/DownloadCenter.tsx) 下载中心：
  - 下载期间展示实时百分比、当前模型名称，用户可自由切换 Git 页面而不中断任务；
  - 下载完成进入模型初始化（WebGPU/WASM 加载），切换为脉冲准备态直至真正可用；
  - 就绪后弹出 i18n 成功通知，右上角图标自动隐藏。

### 3.3 当前域缓存与底部清理能力

- 下载的模型权重持久化在当前域的浏览器 `CacheStorage`（`transformers-cache`）中，仅当前域名可访问。
- 详情表单底部（以及存储/模型卡片内）提供显式的 **「清理本地模型缓存」** 按钮：
  - 展示当前已占用的本地模型缓存大小；
  - 点击后清理当前域缓存的本地模型权重文件，释放磁盘空间，并重置模型状态为未下载，支持用户随时重新下载。

### 3.4 安全与边界约束

- 推理全程在 Web Worker 中运行，避免阻塞 Git DAG 图谱渲染与 UI 交互；
- 禁止本地模型失败后静默回退到任何在线收费或第三方接口；
- 仅在用户明确授权且通过现有隐私脱敏引擎（`RedactionEngine`）处理后发送上下文。
